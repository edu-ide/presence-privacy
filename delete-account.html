한국어

Q Presence(앱 ID app.pnp.presence)의 계정과 서버에 저장된 데이터를 삭제하는 방법입니다. Q Presence는 선택적 Google 로그인만 서버(auth.ugot.uk)를 사용하며, 글·사진·영상·대화 같은 콘텐츠는 애초에 서버를 거치지 않습니다.

한 번도 로그인한 적이 없다면

삭제할 데이터가 서버에 존재하지 않습니다. Google 로그인을 하지 않고 쓴 경우 계정은 기기에서 만들어진 pnp 키뿐이며, 서버에 어떤 계정 레코드도 생기지 않습니다. 앱을 삭제하면 그대로 끝납니다.

방법 1 — 앱 안에서 삭제

[계정 삭제]는 로그인한 상태에서만 나타납니다. Google 로그인을 한 번도 하지 않았다면 앱에 이 메뉴 자체가 없으며, 서버에도 지울 데이터가 없습니다(위 항목 참고). 삭제 경로는 iOS와 Android가 다릅니다.

iOS

  1. 하단 나 탭으로 이동합니다.
  2. 우측 상단의 ⚙ 메뉴를 엽니다.
  3. 계정 섹션에서 [계정 삭제]를 누르고 확인합니다.

Android

  1. 하단 나 탭으로 이동합니다.
  2. 같은 화면의 계정 영역(로그인·로그아웃 항목이 있는 곳)에서 [계정 삭제]를 누르고 확인합니다. Android에는 별도의 ⚙ 설정 메뉴가 없습니다.

확인하면 앱이 DELETE /api/auth/pubkey로 pnp 공개키 ↔ @핸들 매핑을 해제하고 로그아웃합니다. iOS에서 relay에 등록한 APNs 기기 토큰이 있으면 DELETE /api/relay/register로 함께 삭제됩니다. 계정 레코드(이메일·이름·프로필 사진 URL)까지 삭제하려면 아래 방법 2로 요청해 주세요. 사용 중인 버전에 이 메뉴가 보이지 않을 때도 방법 2를 이용하시면 됩니다.

방법 2 — 이메일로 요청

아래 주소로 요청하면 계정 레코드(이메일·이름·프로필 사진 URL)를 포함해 전부 삭제합니다. 계정을 특정할 수 있도록 @핸들(또는 로그인에 사용한 이메일 주소)을 함께 적어 주세요.

삭제되는 것

  • pnp 공개키 ↔ @핸들 매핑 — 만료 없이 보관되던 연결이 해제되어, 공개키로 @핸들을 역조회할 수 없게 됩니다.
  • APNs 기기 토큰 — relay에 등록된 iOS 푸시 토큰(등록한 경우). 앱 내 삭제·이메일 요청 어느 쪽이든 삭제됩니다. 요청과 무관하게 재등록이 없으면 최대 30일 안에 자동 만료되기도 합니다.
  • 계정 레코드 — Google 로그인 시 저장된 이메일 주소·이름·프로필 사진 URL. 방법 2로 요청하면 삭제됩니다.

삭제되지 않는 것과 그 이유

  • 기기의 pnp 계정 키(로컬) — 기기 보안 저장소(Android Keystore / iOS Keychain)에만 있고 서버가 가지고 있지 않아, 서버에서 지울 수 없습니다. 앱을 삭제하면 이 키와 모든 로컬 데이터가 기기에서 사라집니다. 백업해둔 24단어 니모닉이 없으면 pnp 계정은 영구히 복구 불가능합니다.
  • 콘텐츠(글·사진·영상·대화) — 삭제 대상이 아닙니다. 애초에 서버에 저장된 적이 없기 때문입니다. 콘텐츠는 온에어인 동안 기기에서 기기로 종단간 암호화(P2P) 전달되며 세션이 끝나면 사라집니다.
  • 상대 기기에 남은 것 — 상대가 저장 버튼으로 명시적으로 보관한 북마크는 그 사람의 기기 파일에만 있습니다. 서버가 관여하지 않으므로 우리가 지울 수 없습니다.

처리 기간

삭제 요청은 접수 후 30일 이내에 처리합니다. 요청과 무관하게, APNs 기기 토큰은 재등록이 없으면 최대 30일 안에 자동 만료됩니다.

English

How to delete your Q Presence account (app ID app.pnp.presence) and the data stored on our server. Q Presence uses a server (auth.ugot.uk) only for optional Google sign-in; content such as posts, photos, videos, and chats never passes through a server at all.

If you never signed in

There is no server-side data to delete. Without Google sign-in, your account is just the pnp key generated on your device, and no account record is ever created on the server. Uninstalling the app is all there is.

Option 1 — Delete in the app

[Delete account] appears only while you are signed in. If you have never signed in with Google, the app shows no such menu item at all — and there is no server-side data to delete either (see above). The path differs between iOS and Android.

iOS

  1. Open the Me tab.
  2. Open the ⚙ menu at the top right.
  3. Tap [Delete account] in the Account section and confirm.

Android

  1. Open the Me tab.
  2. On that same screen, in the account area (where the sign-in / sign-out item is), tap [Delete account] and confirm. Android has no separate ⚙ settings menu.

On confirmation the app calls DELETE /api/auth/pubkey to unbind the pnp public key ↔ @handle mapping and signs you out. If an APNs device token was registered with the relay on iOS, it is deleted in the same flow via DELETE /api/relay/register. To delete the account record (email address, name, profile picture URL) as well, use Option 2 below. Use Option 2 as well if your version does not show this menu item.

Option 2 — Request by email

Write to the address below and we will delete everything, including the account record (email address, name, profile picture URL). Please include your @handle (or the email address you signed in with) so we can identify the account.

Email dudnjsckrgo@gmail.com

What gets deleted

  • pnp public key ↔ @handle mapping — the link kept with no expiry is unbound, so a handle can no longer be looked up from your public key.
  • APNs device token — the iOS push token registered with the relay, if you registered one. Deleted either way, in-app or by email request. Independently, it also auto-expires within 30 days unless re-registered.
  • Account record — the email address, name, and profile picture URL stored at Google sign-in. Removed when you request deletion via Option 2.

What is not deleted, and why

  • The pnp account key on your device (local) — it lives only in your device's secure storage (Android Keystore / iOS Keychain) and the server never has it, so it cannot be deleted server-side. Uninstalling the app removes that key and all local data from the device. Without your backed-up 24-word mnemonic, the pnp account is permanently unrecoverable.
  • Content (posts, photos, videos, messages) — nothing to delete: it was never stored on a server. Content is delivered end-to-end encrypted device-to-device (P2P) while you are on-air and disappears when the session ends.
  • Copies on other people's devices — a post someone explicitly saved with the bookmark button is kept only in that person's device files. No server is involved, so we cannot remove it.

Processing time

Deletion requests are processed within 30 days of receipt. Independently of any request, APNs device tokens auto-expire within 30 days if they are not re-registered.
